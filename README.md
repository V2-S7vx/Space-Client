# Space Client

A modern Minecraft client project built on Fabric for **Minecraft 1.21.11**.

## Stack

- Minecraft 1.21.11
- Fabric Loader 0.18.1
- Fabric API 0.141.3+1.21.11
- Fabric Loom 1.14.10
- Java 21
- Official Mojang mappings

## Project goals

Space Client will be built as a clean, modular client with a custom UI, configurable modules, keybinds, HUD components, and performance-focused features.

## Development

Use JDK 21. The project uses Fabric Loom and Gradle. The first development milestone is the base client bootstrap; features will be added incrementally.
